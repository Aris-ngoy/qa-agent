# Argent replaces agent-device as device backend, parity-only

`services/runner/src/domains/agent-device/cli.ts:273` (`runAgentDevice`) owns sessions, snapshots, gestures, and installs via a globally installed CLI. Appium is already removed (`docs/devices/remove-appium.md:1`). Argent covers the same iOS sim/device + Android emu/device surface with a tree-first discovery pass, plus TV, desktop/CDP, profiling, flows, and visual regression we do not need in this cut.

We decided the **Argent backend** is a new `domains/argent/` adapter behind the existing `domains/devices/` Screen / Action / Session interface (`session.ts`, `screen.ts`, `interaction.ts`). The runner shells out to a user-installed global `argent` (`npx @swmansion/argent@latest init`, `argent server status` / `argent tools` / `argent run`), same pattern as the current `agent-device` resolve. `yoqa` CLI/HTTP contracts stay stable; coords stay 0–1000. License: Argent source is Apache-2.0; `bin/<platform>/simulator-server`, `bin/darwin/ax-service`, and `native-devtools-ios/*.dylib` are proprietary Software Mansion binaries licensed solely for use within Argent — Yoqa must not vendor, bundle, decompile, reverse-engineer, or redistribute them. Telemetry stays opt-out (`argent telemetry disable`).

Rejected: vendoring Argent binaries into the repo/DMG/npm; defaulting to `--local` devDependency pin; driving MCP directly from the runner; breaking the CLI/HTTP contract; bundling TV D-pad, Electron/Chromium CDP, profiling, flows, or visual regression into the parity swap. Cloud-farm redistribution needs written permission and stays a follow-up.
