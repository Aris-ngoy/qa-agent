# Security Policy

## Supported versions

Security fixes are applied on the latest released YoQA desktop version and on `main`. Older tags are generally not backported unless a critical issue warrants it.

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Instead, report privately using one of:

1. **GitHub Security Advisories** — [Report a vulnerability](https://github.com/Aris-ngoy/qa-agent/security/advisories/new) on this repository
2. **Email** — contact the repository owner via the email listed on their [GitHub profile](https://github.com/Aris-ngoy)

Include as much detail as you can: affected version/commit, impact, reproduction steps, and any proof-of-concept (kept private).

We will acknowledge receipt when possible and coordinate a fix and disclosure timeline. Please give us a reasonable window before public disclosure.

## Non-security bugs

Use normal GitHub issues or pull requests for non-security bugs and feature work. See [CONTRIBUTING.md](./CONTRIBUTING.md).
