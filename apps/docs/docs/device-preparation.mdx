---
title: Device Preparation
description: Prepare iOS and Android devices, and web browsers, for local testing with Yoqa.
---

Yoqa drives devices directly: adb on Android, the simulator tools on iOS simulators, and its own on-device runner on a cabled iPhone. Get the toolchain healthy once, then connect from the desktop UI or CLI.

## Checklist

```bash
yoqa doctor          # Java, Xcode tools, adb, device session
yoqa status          # runner, provider, active device
yoqa devices ios
yoqa devices android
yoqa devices web
```

## iOS

1. Install **Xcode** and accept the license; install additional platforms if prompted.
2. Boot an **iOS Simulator**, or connect a physical device with Developer Mode enabled.
3. For **physical devices**, Yoqa builds and signs its on-device runner for your team the first time you connect.
4. Confirm the device appears in `yoqa devices ios`.

## Android

1. Install Android SDK / platform-tools so `adb` is on your `PATH`.
2. Start an emulator or plug in a device with USB debugging enabled (`adb devices` should list it).
3. Confirm the device appears in `yoqa devices android`.

## Web

1. Install Chrome, Edge, Brave or Chromium in `/Applications` or `~/Applications`.
2. Confirm it appears in `yoqa devices web`. It is listed even when it is not running.

Connecting opens a Yoqa-owned window on a profile Yoqa keeps, so logins survive a disconnect. See [Web](/docs/web) for viewport presets and attaching to a browser you started.

## Connect a session

```bash
yoqa devices connect <device-id>   # use the full id from the list
yoqa devices active
```

The desktop app performs the same connect when you select a device for a run or Manual Inspector.

<Tip>
  If runs fail before the first step, re-check `yoqa status` and the simulator tools or adb — most local issues are toolchain, not test wording.
</Tip>
