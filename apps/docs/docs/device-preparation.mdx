---
title: Device Preparation
description: Prepare iOS and Android devices for local testing with Yoqa.
---

Yoqa drives devices through **agent-device**. Install it once (`npm install -g agent-device@latest`), get the toolchain healthy (`yoqa doctor`), then connect from the desktop UI or CLI.

## Checklist

```bash
yoqa setup ios       # verifies agent-device iOS readiness
yoqa setup android   # verifies agent-device Android readiness
yoqa status          # runner, runtime, provider, active device
yoqa devices ios
yoqa devices android
```

## iOS

1. Install **Xcode** and accept the license; install additional platforms if prompted.
2. Boot an **iOS Simulator**, or connect a physical device with Developer Mode enabled.
3. For **physical devices**, enable Developer Mode and trust the host. agent-device manages its own runner signing — pick the signing identity and runner bundle id in desktop **Settings → iOS** (the runner reads them from there; `AGENT_DEVICE_IOS_TEAM_ID` / `AGENT_DEVICE_IOS_BUNDLE_ID` env vars work as a fallback for `yoqa` CLI runners — see [agent-device installation](https://oss.callstack.com/agent-device/docs/installation)).
4. Confirm the device appears in `yoqa devices ios`.

## Android

1. Install Android SDK / platform-tools so `adb` is on your `PATH`.
2. Start an emulator or plug in a device with USB debugging enabled (`adb devices` should list it).
3. Confirm the device appears in `yoqa devices android`.

## Connect a session

```bash
yoqa devices connect <device-id>   # use the full id from the list
yoqa devices active
```

The desktop app performs the same connect when you select a device for a run or Manual Inspector.

<Tip>
  If runs fail before the first step, re-check `yoqa status` and `agent-device doctor` — most local issues are toolchain, not test wording.
</Tip>
