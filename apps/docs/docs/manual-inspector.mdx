The Manual Inspector is a desktop surface for **exploring** a connected device the way a QA engineer would, then turning what you did into a reusable script.

## Flow

<Steps>
  <Step title="Connect a device">
    Select an iOS or Android device/simulator so an Appium session is active.
  </Step>

  <Step title="Inspect">
    View the live screen. Select elements to target actions (tap, swipe, input, lifecycle).
  </Step>

  <Step title="Build a shell script">
    Actions append to a script (CLI-shaped commands) instead of requiring you to invent locators by hand.
  </Step>

  <Step title="Run or save">
    Execute the script against the session, export a report, or keep it for later regression.
  </Step>
</Steps>

## Command bar

The command bar sits above the script and adds steps that don't need an element selection. Use it to script gestures, app lifecycle, and deeplink flows.

### Screen gestures

- **Swipe up / down / left / right** — appends a directional swipe on the current screen.
- **Wait** — enter seconds and click **Add wait** to pause the script (useful between an app launch and an assertion).

### App control

Use this section when a test needs to leave the app under test, hop into another app, or return via a deeplink. All actions append the equivalent CLI command to the script.

- **App ID** — prefilled with the selected app's iOS bundle ID or Android package. Override it to target a different app.
- **Activate** — bring the app to the foreground (launches it if needed).
- **Terminate** — kill the app.
- **Restart** — terminate then activate the same app.
- **Open Notes** (iOS only) — shortcut that activates `com.apple.mobilenotes`. Handy for pasting a deeplink URL into Notes and tapping it to test universal links.
- **Open URL** — enter a URL and click **Open URL** to open it via the OS. Works for custom schemes (`myapp://path`) and `https://` universal links.
- **Accept alert** / **Dismiss alert** — respond to the next system alert (permissions, App Store prompts, etc.).

### Example: test a deeplink from Notes (iOS)

<Steps>
  <Step title="Open Notes">
    Click **Open Notes** to jump to Apple Notes.
  </Step>
  <Step title="Paste and tap the deeplink">
    Add an **Open URL** step with `myapp://path` — or select the pasted link in Notes and tap it.
  </Step>
  <Step title="Handle any system alert">
    Add **Accept alert** so the "Open in MyApp?" prompt resolves automatically on replay.
  </Step>
  <Step title="Return to the app">
    Add **Activate** with your App ID so the script ends in a known state.
  </Step>
</Steps>

## When to use it

- Learn screen structure before writing natural-language cases.
- Reproduce a bug with an exact sequence of gestures.
- Script cross-app or deeplink flows (Notes → universal link → your app) that are hard to describe in natural language.
- Produce a **saved script** after you understand the happy path (complementary to AI agent runs).

For autonomous NL cases, use [Test Cases](/docs/test-cases) + Runs. For agent-driven debugging from the terminal, use [CLI for agents](/guide/cli-for-agents).
