---
title: Device Capabilities
description: Custom driver capabilities were removed — the agent-device backend needs none.
---

Under the hood, Yoqa drives your app through **agent-device**. There are no custom driver capabilities to set: sessions open the app's bundle id / package directly, and gestures run through snapshots with refs.

## What changed

Custom **Appium capabilities** (app-level and case-level, e.g. `appium:autoLaunch`, `appium:appActivity`) were removed with the Appium backend. If you are migrating:

- **Start without launching the app** — connect to the device, then describe the real start in the case instructions ("Open example.com and sign in…"). `yoqa devices connect` opens a session on a sensible default app; `action open-url` navigates from there.
- **Android entry points** — install the build (`yoqa builds create`), then launch by application id. Deep links work via `action open-url`.

## Local note

This applies to local sessions started by the Yoqa runner. Cloud-specific options will be documented when cloud runs ship.
